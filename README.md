# Marco R. Ocampo: Art Portfolio (single page)

Open `index.html` through a web server or deploy the folder (Netlify, GitHub Pages).

All words, links and file names live in `js/rooms.js`. Look for the EDIT markers:
- `VIDEO.url`: paste your YouTube link; set each chapter's `t` (seconds)
- `SONG`: artist, year, note
- `PHOTO`, `MANGA`: captions and notes
- `APPENDICES`: add images to `img/appendix/` and set `img: "img/appendix/name.webp"`
